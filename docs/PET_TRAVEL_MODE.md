# 선택형 반려동물 동행

기존 여행·캐릭터·지도·엽서·시즌을 유지한 추가 모드다. 홈의 **반려동물 동행** 또는 더보기에서 진입한다. 기존 배경·색상·카드·버튼과 안내 캐릭터를 그대로 사용하며, 가상 안내 캐릭터와 실제 함께 타는 아이는 구분한다.

2026-11-15에는 **펫 휴식 도우미·공식 안내 오프라인 동반 조건 검색**을 추가했다. 아래 개인 장소 수첩과 별개 기능이다. 최신 범위·출처·타이머 제한은 [반려동물 이동 도우미](PET_MOBILITY_FEATURES.md)를 따른다.

## 사용 흐름

1. **우리 아이 등록**: 이름과 반려견/반려묘/기타를 선택하고 펫 데이터 로컬 저장에 명시 동의한다. 현재 한 프로필을 지원한다.
2. **출발 준비**: 나들이/미용·맡김/병원 이동 목적별 준비 메모를 선택·추가한다. 드라이브 기록 저장을 켠 뒤 ‘이번 동행 준비 시작’을 누른다.
3. **이동과 정차**: 이후 시작한 드라이브를 연결한다. 주행·상태 미확인·제한 중에는 상세·입력·확인창을 잠근다. 정차 후 보호자가 물품과 다음 일정을 직접 확인한다.
4. **함께한 펫 엽서**: 완료 드라이브가 있어야 명시 저장할 수 있다. 한마디와 다음 여행 메모는 선택이다. 기록 시간과 보호자가 선택한 동행만 표시하며 원문은 엽서를 직접 열 때 보여 준다.
5. **다음 출발**: 저장한 준비 메모를 확인·체크·삭제한다. 모드를 꺼도 기존 수첩/엽서는 유지한다. 진행 중 준비를 종료하는 모드 전환은 확인창을 거친다.

프로필 수정은 동행 마무리/준비 취소 후 허용한다. 준비 시작 전에 이미 완료된 드라이브를 새 동행으로 자동 가져오지 않는다. Production에 합성 드라이브 생성 기능을 추가하지 않았다. 정차만으로 실제 탑승·도착·휴식·반려동물 상태를 확정하지 않는다.

## 기존 메뉴와 연결

| 메뉴 | 모드를 켰을 때 |
|---|---|
| 동행 | 함께 타는 아이 이름이 있는 펫 동행 진입 버튼 |
| 지도 | 우리 아이 장소 수첩 진입. 기존 탐험 지도는 유지 |
| 엽서 | 기존 지역 컬렉션 위에 펫 엽서 진입 카드 |
| 시즌 | 첫 차 나들이 패스. ‘기존 시즌 패스 보기’로 기존 화면 이용 가능 |
| 기억/설정/더보기 | 동행 수첩과 펫 설정 진입 |

## 상시 무료 펫 패스

| 챕터 | 조건 | 실제 보상 |
|---|---|---|
| 오늘의 동행 준비 | 명시 동의 후 프로필 등록 | 동행 발자국 배지, 프로필에 표시 |
| 우리만의 나들이 | 완료 드라이브를 펫 엽서로 직접 저장 | 발도장 프레임, 엽서에 선택 적용 |
| 다음에도 함께 | 다음 출발 메모 저장. 제시 문구 선택도 가능 | 별빛 프레임, 엽서에 선택 적용 |

별도 수령하며 중복 지급하지 않는다. 기존 XP·거리 보너스·레벨·기존 시즌 원장과 Care 판단은 바꾸지 않는다. 수령한 꾸미기 보상은 원본 드라이브 삭제 후 내용/Trip ID 없이 유지하고, 펫 데이터 전체 삭제에서는 함께 지운다. 펫 패스에 기한·구매·결제를 추가하지 않았다.

## 장소와 정보 범위

장소 이름·메모·다시 가고 싶은 곳 여부는 보호자가 직접 저장·수정·삭제한다. **현재 위치·실제 방문 증거·공식 동반 허용 정보가 아니다.** 지도 안개 해제/지역 엽서 발급에 쓰지 않으며 입장 조건·운영정보는 방문 전 직접 확인하도록 표시한다. 위치/POI API나 가상의 동반 가능 장소를 추가하지 않았다.

## 저장·동의·삭제

- 앱 전용 noBackup의 `roadmate-production/pet` 또는 `roadmate-demo/pet` 아래 별도 `pet-travel.v1.bin`을 기존 Keystore/JCA AES256-GCM으로 보호한다. Pet domain schema는2이며 기존1을 읽는다. 파일 이름·암호화 키·Trip schema와 독립 경계를 유지한다. Production/Demo UID·경로·키 경계를 유지한다. 기존 Trip 파일·schema·XP 원장을 변경하지 않는다.
- OS file lock 아래 최신 값을 읽고, 암호화 staging fsync → 재인증/도메인 비교 → atomic replace 성공 후 발행한다. 키 누락/변조/IO 오류를 표시하며 자동 초기화하지 않는다.
- 펫 프로필·준비/장소 메모·명시 저장한 펫 엽서에 별도 로컬 동의를 받는다. 기존 감성 기억을 자동 복사하지 않는다. 엽서 한마디는 해당 드라이브에 연결한 선택 메모다.
- 원래 드라이브 삭제/기록 동의 철회는 연결된 펫 엽서와 그 엽서에서 만든 메모에 전파한다. 별도로 추가한 준비/장소 메모는 독립 목적이며 펫 데이터 삭제로 지운다.
- ‘이 펫 엽서 삭제’는 해당 엽서와 연결 메모만 지운다. ‘펫 데이터 전체 삭제’는 프로필·동의·모드·준비·장소·메모·펫 엽서·전용 보상을 제거한다. 원래 여행·시즌·XP는 유지한다.
- 두 파일의 삭제는 분산 트랜잭션이 아니다. 화면은 현재 원본/동의를 다시 확인한다. 정리 쓰기 실패 시 민감 UI를 숨기고 다음 읽기에도 원본을 확인하여 삭제한 연결이 되살아나지 않게 한다.

새 SDK·permission·dependency·서버·외부 전송은 없다. 최종 법적 동의 문안은 별도 검토 대상이다.

## 여행 체험

Demo: ‘이번 동행 준비 시작’ → ‘지도에서 나들이 체험’ → 방문 체험 → 정차 후 펫 엽서 저장. 기존 **DEMO/SIMULATED** 경계를 따른다. Production은 실제 관측·저장한 완료 드라이브만 사용한다.

최신 회귀와 이전 펫 모드/이동 도우미 AVD 관측은 [검증 요약](VALIDATION_SUMMARY.md), 제출 APK의 최종 해시는 [검증 현황](VALIDATION_SUMMARY.md)를 따른다. 과거 원시 증거는 로컬 보관소에 보존한다. 사용자 직접 인수는 별도다. 실차·전체 접근성 인증·복수 프로필·사진/웨어러블·실시간 장소 API·건강/멀미/차량 방치/실내 안전 온도 감지·차량 제어는 이번 범위에 포함하지 않는다.
