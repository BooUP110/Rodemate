# 사용자 직접 검수

## 추가 검수: 펫 이동 도우미

- 펫 동행 → 펫 휴식 도우미에서 간격을 직접 선택하고 시작한다. 정차 대기도 누적하고 ‘함께 쉬기 시작’에서는 멈추는지 확인한다. 확인 항목을 고른 뒤 명시 완료해야 횟수가 증가하고 다음 간격이 시작된다.
- 앱 재시작/배경 복귀에서는 일시정지된 저장 시간으로 복원하고 직접 이어가는지 확인한다. 주행 중 상세/입력이 잠기는지 확인한다. 실제 휴식/탑승 감지로 설명하지 않는다.
- 동반 조건 검색에서 서울·강릉·제주, 종류·검색어를 바꾼다. 정동진 항목에 체중6kg을 입력하면 명시6kg 미만 조건과 불일치하는지, 이동장 없음도 조건 불일치로 나타나는지 확인한다.
- 상세의 정보 출처·확인일·미확인 조건을 확인한다. 검색 결과를 입장 승인·실시간·근처 검색으로 설명하지 않는다. 반려묘/기타 조건 미기재를 임의 허용으로 처리하지 않는지 확인한다.
- 정차 화면의 레이아웃과 큰 글꼴·좁은 창에서의 이용을 직접 검수한다. [상세 동작과 한계](PET_MOBILITY_FEATURES.md)를 따른다. 사용자 인수는 별도 PENDING이다.

## 추가 검수: 반려동물 동행

현재 표시 이름은 **카펫**이며 Demo에는 시뮬레이션 표시가 있다. 홈 ‘반려동물 동행’ → ‘우리 아이 등록’에서 별도 동의 후 시작한다. [상세 안내](PET_TRAVEL_MODE.md)의 준비→이동→정차→엽서→다음 메모 흐름을 확인한다.

- 일반 모드로 복귀해 기존 지도·캐릭터·시즌이 유지되는지 확인한다. 펫 모드의 시즌에는 전용 패스와 기존 시즌으로 돌아가는 버튼이 있다.
- 전용 패스의 배지·프레임을 수령하고 실제 펫 엽서에서 적용 상태를 확인한다. 준비 시작 전에 완료된 드라이브는 연결되지 않는다.
- Demo에서는 기록 저장 켜기 → 이번 동행 준비 시작 → 지도에서 나들이 시연 → 방문 시연 → 정차 후 명시 저장 순서로 촬영한다. 실제 차량 여행과 구분한다.
- 주행/상태 미확인 때 메모·입력창이 닫히는지, 재시작 후 복원되는지 확인한다. 삭제 검수는 본인이 삭제해도 되는 데이터에서만 진행한다.

자동 검증과 별개로 위 항목의 사용자 인수는 아직 PENDING이다.

**USER_ACCEPTANCE_PENDING.** 아래 항목은 사용자가 실제 화면에서 확인한 뒤 체크한다. 자동 테스트 결과와 직접 인수 판정을 구분한다.

## 준비

[빌드 및 실행](BUILD_AND_RUN.md)에 따라 Production/Demo debug APK를 설치하고 Pleos AVD 시스템 런처에서 실행한다. 표시 이름은 둘 다 카펫이므로 앱 ID와 Demo의 SIMULATED 표시로 구분한다. Console을 활성 상태로 두고 속도0/Park에서 시작한다. 기본 Production release는 미서명이며, 명시적 내부 콜라보 빌드의 제출용 Demo release는 디버그 키로 서명한다.

권한 거부/연결 미확인/주행 제한 시 콘텐츠가 잠길 수 있다. 실제 화면이 보이지 않으면 런처 준비를 확인하고 앱 서랍에서 다시 연다. 검수용 데이터와 기존 사용자 기록을 구분하며 기존 기록을 임의 초기화하지 않는다.

## Production

동행 홈 → 설정의 기록 저장 선택 → 실제 이동/정차 → 완료 카드 → 선택 회고 → 저장/수정 → 재실행/복원 → 삭제 확인 → 재실행 순서로 확인한다. Console Drive10km/h를 10초 이상, 완료는 Park0km/h를 120초 이상 유지한다. 종료 후 속도0/Park 및 변경한 입력을 원래 값으로 복원한다.

- [ ] 홈의 연결 상태·현재 드라이브·동반자 표현이 자연스럽다.
- [ ] 실제 하향등·누적거리·앞좌석 왼쪽 목표 온도 읽기가 차량 제어로 오인되지 않는다.
- [ ] 외기 온도가 차량 센서 값임을 이해하고, 연결 미확인/오래된 값이 현재 값으로 표시되지 않는다.
- [ ] 정차 설정에서 선호 온도를 직접 저장/수정/재실행/삭제하고, 요청한 안내가 수동 조절 안내임을 확인했다.
- [ ] 주행/제한 시 온도 선호 입력과 안내가 사라진다.
- [ ] 기본10/120초 Trip과 짧은 정차/재개가 동작한다.
- [ ] 기억 카드에 미확인 위치/날씨/Trip 거리가 만들어지지 않는다.
- [ ] 회고는 선택이며 입력·키보드 닫기·저장·정리 완료 전 수정이 가능하다.
- [ ] 재실행 시 저장한 내용만 복원되고, 삭제 확인 후 재실행해도 복원되지 않는다.
- [ ] 기록 저장과 별도 기억 저장 동의가 구분된다.
- [ ] 기억 보기 전 원문이 노출되지 않고, 직접 연 기억과 UTC 월간 수치가 저장한 기록에 맞는다.
- [ ] 기록 삭제 후 열린 기억과 기간 집계에서 즉시 제거되고 재실행해도 돌아오지 않는다.
- [ ] 무료 시즌/수령 조건과 지역 없는 컬렉션 빈 상태가 이해된다.
- [ ] 주행/정책 미확인 상태에서 상세·설정·입력·확인창이 잠긴다.

정리 완료 후 회고는 읽기 전용이다. 별도 기억은 설정 허용과 항목 확인이 필요하다. 삭제 후에도 시즌/엽서 등 독립 보존 항목이 있는 정책은 [안전 및 개인정보](SAFETY_AND_PRIVACY.md)를 참고한다.

## Demo

[시연 동선](SUBMISSION_DEMO_FLOW.md)에 따라 별도 앱으로 전환한다. 일부 합성 주행 제한에서는 선택기가 숨겨지므로 안내된 Demo 전용 host 명령으로 다음 시나리오를 선택한다.

- [ ] DEMO/SIMULATED 표시와 합성 데이터 안내가 명확하다.
- [ ] Light/HVAC/Rest/Warning과 동반자 선택/상호작용을 확인했다.
- [ ] 회고·가상 지역 엽서·시즌·보상 수령을 확인했다.
- [ ] 시나리오가 Demo 기록/합성 동의를 초기화할 수 있음을 이해한다.
- [ ] 제안 수락이 실제 차량 변경 성공으로 표현되지 않는다.

## 화면과 접근성

- [ ] 글자 크기·버튼 크기·포커스 순서·스크롤이 사용하기 편하다.
- [ ] 확인창/키보드 전환 시 잘림과 시스템 영역 겹침이 없다.
- [ ] 실제 앱 사용자 설정에서 글자 확대를 확인했다.
- [ ] 가능한 입력 장치에서 포커스/로터리/접근성 동작을 확인했다.
- [ ] 미확인/오류 상태를 정상이나 위험으로 과장하는 문구가 없다.

현재 확대 접근성 검수는 PARTIAL이고 로터리/스크린리더 전체 검수는 미실행이다. 자세한 범위와 AVD 한계는 [검증 요약](VALIDATION_SUMMARY.md)에 있다.

## 결과 전달

앱 종류, 화면, 재현 순서, 기대/실제 결과, Console 상태를 전달한다. 개인정보나 인증정보는 포함하지 않는다. 사용자의 통과 확인 전에는 USER_ACCEPTANCE_PASS·최종 제출·서명·업로드로 넘어가지 않는다.
