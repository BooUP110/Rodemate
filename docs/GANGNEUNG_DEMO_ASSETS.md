# 치이카와 강릉 패스 이미지 제작 요청서

## 먼저 제작할 그림

`image-create/maps/gangneung.png`를 색감과 붓질의 기준으로 첨부한다. 패스 표지와 이동 장면에는 이 그림을 사용한다. 아래 네 장소의 기본 배경과 경포대·안목의 깊이 레이어가 필요하다. **경포대 배경 → 경포대 중경 → 경포대 전경**을 먼저 받으면 영상의 대표 장면을 확인할 수 있다.

### 공통으로 붙일 프롬프트

> 제공한 강릉 해변 일러스트의 색감, 손으로 칠한 듯한 붓질, 부드러운 그림자와 따뜻한 여행 동화 분위기를 이어가는 게임 배경을 만들어 주세요. 16:9 가로, 1920×1080 PNG, 서 있는 작은 캐릭터의 눈높이에서 바라본 고정 카메라 구도입니다. 이미지 아래 25%는 대사창이 덮을 수 있도록 단순하게 그리고, 화면 중앙 48~83% 너비와 45~72% 높이에는 캐릭터 두 명이 겹치지 않고 설 수 있는 여백을 주세요. 화면 위에서 약 68% 내려온 높이에 캐릭터가 발을 디딜 수 있는 마른 지면이나 평평한 길이 이 구간을 지나가게 그려 주세요. 주요 풍경은 그 여백 바깥이나 인물 뒤로 읽히게 두세요. 인물, 차량, UI, 지도, 글자, 워터마크 없이 풍경만 그려 주세요. 현장 참고 사진을 함께 붙이면 장소의 특징을 참고해 주세요.

### 경포대와 안목의 깊이 레이어 네 장

각 장소의 **완성한 기본 배경을 참조 이미지로 다시 첨부**하고 중경과 전경을 한 장씩 요청한다. 레이어는 **해당 장소 배경과 정확히 같은 픽셀 크기와 구도**를 사용한다. 1920×1080을 권장하며, 생성 결과가 기존 이미지와 같은 1672×941이라면 해당 장소의 레이어도 그 크기로 맞춘다. 물체를 화면 중앙으로 자동 배치하거나 크롭하지 않는다. 회색이나 바둑판무늬가 보이는 합성본 대신 실제 알파 채널이 있는 투명 PNG가 필요하다.

| 파일 | 레이어별 프롬프트 |
|---|---|
| `story-gangneung-gyeongpodae-mid.png` | 참조 배경의 카메라를 고정하고 인물 뒤에 놓일 가느다란 물가 갈대와 멀리 이어지는 낮은 길가 식물만 같은 위치에 그려 주세요. 물, 정자, 하늘, 땅, 글자, 인물은 투명하게 남겨 주세요. 호수 중앙은 비워 주세요. |
| `story-gangneung-gyeongpodae-front.png` | 같은 카메라를 유지하고 관객과 가까운 왼쪽 또는 오른쪽 끝에 살짝 흐릿한 갈대 잎만 그려 주세요. 인물의 얼굴, 달과 반사가 놓일 오른쪽 하늘과 물은 비워 주세요. 나머지는 투명하게 남겨 주세요. |
| `story-gangneung-anmok-mid.png` | 참조 배경과 동일한 위치에 인물 뒤로 보이는 낮은 산책로 난간 일부나 잔잔한 해변 식물만 투명 레이어로 그려 주세요. 오른쪽의 엽서 영역은 비워 주세요. 배경 풍경은 제외해 주세요. |
| `story-gangneung-anmok-front.png` | 같은 카메라에서 프레임 양쪽 가장자리의 가까운 해변 풀과 부드럽게 흐린 잎만 그려 주세요. 엽서가 뜨는 오른쪽 중앙과 화면 아래 대사창 영역에는 큰 물체를 두지 마세요. 나머지는 투명하게 남겨 주세요. |

깊이 레이어를 움직일 때 뒤쪽에 원래 물체가 그대로 보이면 이중으로 겹쳐 보인다. 중경과 전경으로 분리한 물체는 필요할 때 해당 배경에서 지운 버전도 함께 제공한다. 오죽헌과 강문해변에 같은 깊이를 추가하려면 각 배경에 `-mid.png`와 `-front.png`를 붙이고 위 규격을 그대로 적용한다.

### 결말 엽서와 캐릭터 동작

- **결말 엽서 속 그림** `story-gangneung-postcard-art.png`. 안목 배경의 화풍을 유지한 3:2 가로 그림. 물 위에 비친 달, 멀리 보이는 따뜻한 불빛, 화면 한쪽의 작은 파도. 엽서 테두리, 소인, 글자, 캐릭터 없이 내부 그림만 그린다. 앱이 테두리와 공개 애니메이션을 얹는다. 이 파일이 오기 전에는 안목 장면 그림을 사용한다.
- **캐릭터는 기존 동작 시트를 먼저 사용한다.** 바꿀 때만 치이카와·하치와레·우사기를 캐릭터별로 한 장씩 요청한다. 같은 캐릭터의 원본을 참조해 정면에 가까운 ¾ 시점, 같은 얼굴 비율과 발바닥 높이, 투명 배경을 유지한다. 정사각형 1536×1536의 2×2 그리드로 각 칸에 전신을 하나씩 배치한다. 왼쪽 위 기본 자세, 오른쪽 위 한 발 내딛기, 왼쪽 아래 한 손으로 인사, 오른쪽 아래 눈을 감고 웃는 반응이다. 그림자와 소품 없이 테두리에서 손과 귀가 잘리지 않게 한다. 앱에 적용할 파일명은 `chiikawa-idle.png`, `hachiware-idle.png`, `usagi-idle.png`다. 원본 시트는 교체 전에 보관한다.
- **기본 동행 두 종은 기존 시트를 사용한다.** 앱의 `app/src/main/assets/original-companions/` 아래에 `wave-otter/`와 `starlight-somsom/`가 있다. 각 폴더의 `00-idle.png`는 기본 자세 시트이며, 두 캐릭터가 공유하는 동작 번호는 같다. 예를 들어 오른쪽 걷기는 `01-walk-right.webp`, 편지 열기는 `14-open-letter.webp`다. 원본 PNG는 로컬 `image-create/characters/`에, 미적용 원본은 `etc/character-drafts/`에 보관한다.

생성한 PNG는 `development/collab-preview/image-create/`에 둔다. 기본 Run과 내부 Demo에서 함께 사용하는 배경·레이어는 검수 후 `app/src/main/assets/journey/design/`에 배치한다. 콜라보 캐릭터 시트는 내부 Demo의 `development/collab-preview/assets/companion-previews/`에 배치한다.

## 받은 파일 검수

- `image-create/maps/gangneung.png`는 표지와 이동에 사용한다. 밝은 낮 해변 장면이라 경포대의 밤 호수와 안목 결말용 배경을 별도로 받는다.
- 서울·경주·제주 지도 원본도 `image-create/maps/`에 있다. 서울·제주 대체 구도는 `etc/scenery/`에 보관한다.
- 홈 풍경, `care-car.png`, `drive-memory.png`, `drive-empty.png`, `map-fog.png`, 랜드마크 두 장의 원본은 `image-create/ui/`에 있다. 이번 강릉 스토리 영상용으로 다시 생성할 필요가 없다.
- `ui-design-reference.png`는 버튼과 글자가 들어간 레이아웃 참고다. 앱에서는 대사와 버튼을 직접 표시한다.

## 영상에 담을 순서

표지에서 세 캐릭터가 등장한다. 오죽헌에서 빈 엽서를 발견하고, 경포대에서 현장 위치 인증을 누른 뒤 물에 비친 달 조각을 고른다. 강문해변에서 편지의 단서를 찾고, 안목에서 네 장소의 순서를 맞혀 완성 엽서를 건넨다. 끝에는 엽서와 무료 의상 한 가지를 보여준다. 이동 장면과 나머지 확인 버튼은 편집에서 짧게 이어 붙일 수 있다.

## 콜라보 동작과 중간 프레임

치이카와·하치와레·우사기의 기존 기본 4컷은 캐릭터별 기준 이미지로 사용한다. 장면에서 바로 드러나는 양방향 걷기·인사·대화·엽서 건네기를 먼저 제작하고, 다음에 장소별 동작을 채운다. 콜라보 원화는 내부 시연 폴더에서 관리한다.

| 순서 | 파일 이름 | 동작과 화면 |
|---|---|---|
| 1 | `01-walk-right`, `02-walk-left` | 홈 산책. 좌우 각각 한 장. 마지막 발 자세가 첫 컷으로 연결되는 반복 동작 |
| 1 | `06-wave`, `08-talk` | 인사와 대사. 같은 위치에 서서 손 또는 입과 표정이 움직임 |
| 1 | `16-give-postcard` | 안목 결말과 엽서 펼치기. 가슴 앞에 보여주기 → 앞으로 건네기 → 건넨 뒤 웃기 |
| 2 | `03-turn-left`, `05-stop-right` | 홈에서 멈추고 돌아서기. 좌우 걷기 시트의 끝과 시작을 기준으로 연결 |
| 2 | `11-think`, `12-point`, `13-pick-up-postcard` | 단서 듣기, 오른쪽 가리키기, 엽서 조각 발견 → 집기 → 보여주기 |
| 2 | `14-open-letter`, `18-react` | 강문에서 봉투 열기와 도착 반응. 우사기는 귀와 표정, 하치와레는 시선과 고개, 치이카와는 양손과 표정으로 반응 |

### 원화 요청문

> 첨부한 **[캐릭터 이름]** 원본만 기준으로 **[동작]**을 그려 주세요. 1536×1536, 투명 PNG, 동일 크기의 2×2 칸에 전신 4컷을 왼쪽 위부터 순서대로 배치합니다. 얼굴·몸 비율·색·선 굵기·귀 모양을 고정하고, 카메라와 발 기준선이 흔들리지 않게 해주세요. 걷기 방향은 화면 기준입니다. 컷마다 움직이는 부위만 바꾸고 배경·바닥·글자·격자선을 넣지 마세요. 소품을 드는 손과 소품 크기를 장면 내내 유지해 주세요.

### 중간 프레임 요청문

> 첨부된 2×2 시트의 원화 4컷을 시작과 끝의 기준으로 사용해 주세요. 한 번에 4×4 시트를 새로 그리지 말고, **[시작 컷] → [끝 컷]** 사이의 중간 자세만 별도의 투명 PNG로 만들어 주세요. 카메라, 중심, 발 높이, 선 굵기와 색은 고정하고 팔·다리·귀·소품 위치만 단계적으로 바꿉니다. **걷기처럼 반복되는 동작**은 1→2, 2→3, 3→4, 4→1 사이에 각각 3장입니다. **한 번 재생되는 동작**은 1→2와 2→3 사이에 각각 4장, 3→4 사이에 4장입니다. 각 파일에 어느 두 컷 사이인지와 순서를 표시해 주세요.

반복 동작과 단발 동작 모두 기존 4컷과 새 12컷을 시간순으로 합쳐 4×4 시트로 저장한다. 우선 수달·솜솜의 `01-walk-right`, `02-walk-left`, `16-give-postcard`에 적용하고, 치이카와·하치와레·우사기는 원화 확인 후 같은 순서로 진행한다. 앱은 `-16.webp`가 있으면 사용하고, 없으면 기존 2×2 `.webp`를 읽는다. 재생 시간은 유지하면서 프레임 사이 간격을 줄인다. 내부 시연용 동작 경로 예시는 `development/collab-preview/assets/companion-previews/usagi/01-walk-right-16.webp`다. 내부 APK의 **시연 선택 → 화면 둘러보기 시작 → 목차 → 콜라보 캐릭터 시연**으로 들어가면, 로컬 카탈로그에 있는 세 캐릭터를 시연 슬롯에서 바로 선택할 수 있다.

### 내부 시연판 적용 현황

- 치이카와는 오른쪽 걷기와 엽서 건네기에 16컷을 사용한다. 왼쪽 걷기는 발이 교차하는 기존 4컷을 사용한다.
- 하치와레는 `05-stop-right.webp`로 오른쪽 걷기에서 멈추는 모습을 재생한다.
- 하치와레·우사기는 오죽헌의 엽서 조각 줍기 `13-pick-up-postcard.webp`, 강문해변의 봉투 열기 `14-open-letter.webp`, 안목해변의 완성 엽서 건네기 `16-give-postcard.webp`를 4컷으로 재생한다. 동작 파일은 `companion-previews/<캐릭터 ID>/`에 둔다.
