# 제품 기능과 제공 범위

## 차량 연결

기본 앱은 실제 Pleos 하향등·누적 주행거리·앞좌석 왼쪽 공조 목표, AAOS 외기·motion·UX 제한을 읽는다. Trip은 기본10초 관측 후 시작하고 Park120초에서 완료한다. 미확인 상태를 정상 값으로 채우지 않으며, 주행·제한 때 상세/입력을 닫는다.

## 기기에 남기는 기억

명시 동의 후 암호화 드라이브 기록·선택 회고·별도 기억 회상·UTC 월간 기록 사실 요약을 제공한다. 온도 선호는 사용자가 직접 저장하고 정차 중 요청한 수동 조절 안내에 사용한다. 오리지널 동반자와 무료 로컬 시즌이 연결되며 보상은 별도 수령한다.

## 반려동물 동행

기존 모드를 유지한 선택 기능이다. 별도 동의로 프로필·목적별 준비·개인 장소 수첩·완료 드라이브 연결 펫 엽서·다음 메모·무료 패스/프레임을 사용한다. [이용 안내](PET_TRAVEL_MODE.md).

휴식 도우미는 보호자가 정한 간격으로 앱 전경에서 관측한 동행 시간을 관리한다. 정차 대기도 포함하고 배경/관측 공백에서는 일시정지하며, 재개·실제 휴식 확인은 보호자가 직접 한다. 공식 동반 조건 검색은 서울4·강릉1·제주3곳을 담은 오프라인 목록이다. [시간 의미·출처·조건 한계](PET_MOBILITY_FEATURES.md).

## 여행 체험

별도 앱 `io.booup.roadmate.demo`에서 **DEMO · SIMULATED** 표시와 함께 모의 차량·방문·엽서·강릉 이야기·확장 패스/게임을 체험한다. 메뉴는 `더보기 → 여행 체험`이다. 임시 화면 둘러보기는 기존 기록과 분리되고 펫 저장소가 없으므로 펫 기능은 일반 체험 홈에서 사용한다. 일부 검증용 선택 항목은 체험 앱의 기록·모의 동의를 초기화한다.

프리미엄 미리보기는 결제가 없고, 방문자·반응·순위는 로컬 가상 데이터다. 실제 방문·결제·제휴·다른 사용자의 이용 실적이 아니다. 내장 행정경계 지도와 실제 위치 공급자도 구분한다.

## 현재 제한

앱 관측 운전 시간 규칙은 실제 피로·권위 있는 연속 운전/휴식을 판정하지 않는다. 경고 일회 조회는 연결되어 있으나 현재 AVD 실제 목록 수신이 확인되지 않았다. 자동 야간·자동 공조는 필수 신뢰 입력이 부족해 기본 앱에서 활성화하지 않았다.

실제 위치 provider가 없어 자동 방문 인증·지역 엽서 발급은 비활성이다. 누적 차량 거리를 Trip 거리로 차분하지 않는다. 실제 음성·내비·차량 제어·외부 LLM·서버·클라우드·결제는 제공하지 않는다. 실차·Market/DO·전체 접근성은 후속 검증이다. [로드맵](DEVELOPMENT_PHASES.md).
