# 카펫 제품 기획

차량과 연결된 동행, 여행의 기억, 반려동물과의 나들이 준비를 하나의 경험으로 연결한다. 일반 여행 모드를 유지하면서 보호자가 필요할 때 펫 모드를 선택하는 구조다.

## 기획 배경

차 안의 시간은 여행을 준비하고 함께 이동하며 도착 후 기억을 나누는 하나의 경험입니다. 그러나 차량 상태, 여행 기록, 함께 타는 가족의 준비사항은 각각 확인하게 됩니다. 카펫은 차량과 연결된 동반자가 이 과정을 이어주도록 기획했습니다. 원래의 차량 케어·캐릭터·드라이브 기억이라는 서비스 의도에, 반려동물과 함께 이동하는 보호자의 구체적인 준비와 정보 확인 기능을 더했습니다.

특히 반려동물 동반 나들이에는 물품 준비 외에도 이동 중 쉬어갈 계획과 목적지의 동물 종류·체중·이동장 조건 확인이 필요합니다. ‘반려동물 동반 가능’이라는 한 줄만으로는 보호자가 자기 아이의 이용 조건을 판단하기 어렵습니다. 카펫은 보호자가 정한 휴식 계획과 공식 기관·운영사의 명시 조건을 구분해서 보여주고, 모르는 조건은 추가 확인이 필요하다고 알립니다.

사용자는 일반 여행 모드를 그대로 쓰거나 반려동물 동행을 선택할 수 있습니다. 캐릭터와 시즌은 다시 방문할 즐거움을 주고, 실제 준비 수첩·휴식 확인·조건 검색·여행 기억은 차량 생활에 쓰이는 효용을 제공합니다. 이 문제 정의는 제품 가설이며 시장점유율·안전 개선 효과를 실측했다는 주장은 아닙니다.

## 핵심 기능과 차량 환경

① 차량과 연결된 동행: Pleos Vehicle SDK로 하향등·누적 주행거리·앞좌석 왼쪽 공조 목표를, public AAOS API로 외기 온도·속도/기어 기반 motion과 화면 제한을 읽습니다. 수신 상태·출처·신선도를 확인하고 미지원·권한 거부·미확인을 구분합니다. 정차 중에는 저장한 온도 선호와 현재 값을 보고 사용자가 직접 조절하도록 안내합니다. 앱이 차량 설정을 바꾸지는 않습니다.

② 드라이브의 기억: 실제 motion 관측으로 Trip의 시작·짧은 정차·재개·완료를 구분하고, 동의한 기록을 기기에 저장합니다. 정차 후 기억 카드와 선택 회고를 남기며, 별도로 동의한 기억을 직접 다시 열거나 UTC 월간 기록 사실을 확인할 수 있습니다. 오리지널 동반자, 여행 엽서·도감·시즌 보상은 이동 경험을 이어주는 표현층입니다. 실제 위치 자동 방문과 지역 엽서 발급은 아직 연결하지 않았고, 강릉 이야기와 가상 방문·지역 엽서·확장 패스는 Demo에서 시뮬레이션합니다.

③ 반려동물 특화 동행: 별도 동의로 한 아이를 등록하고 목적별 준비 체크, 개인 장소 수첩, 완료 Trip과 연결한 펫 엽서·다음 출발 메모를 사용합니다. 상시 무료 펫 패스에서 배지와 프레임을 직접 수령해 적용합니다. 휴식 도우미는 보호자가 간격과 해당 저장에 동의하고 시작하는 독립 세션입니다. 앱 전경에서 확인한 동행 시간만 누적하고 배경/관측 공백에서는 멈추며, 실제 쉬었다는 확인은 보호자가 직접 합니다. 건강·피로·실제 탑승을 감지하지 않습니다.

④ 공식 정보 기반 동반 조건 검색: 서울4·강릉1·제주3곳의 공식 공개 사실을 내장하고 지역·이름·종류로 검색합니다. 동물 종류와 선택 입력한 체중·이동장 조건을 명시된 규칙과 비교하여 일부 일치·추가 확인·명시 불일치를 구분합니다. 출처·확인일·미기재 조건을 보여주며 입장 가능을 보증하지 않습니다. 현재 위치·실시간 영업·전국 POI 서비스가 아닌 오프라인8곳의 MVP입니다.

차량 화면의 특징은 이동과 정차가 서비스의 입력이라는 점입니다. 실제 motion과 플랫폼 UX 제한을 독립 확인하고 주행·미확인 때 상세/입력/확인창을 닫습니다. DO는 선언하지 않았습니다. 캐릭터·보상·유료 여부가 안전 판단을 바꾸지 않으며 실제 차량 제어 경로도 없습니다.

## 사용 시나리오

주말에 반려견과 나들이를 떠나는 보호자가 정차 상태에서 카펫을 엽니다. 오리지널 동반자와 차량 연결을 확인하고, 반려동물 동행을 선택해 우리 아이를 등록합니다. 준비 수첩에서 물품과 다음 일정을 확인하고 휴식 도우미의 간격을 직접 선택합니다. 동반 조건 검색에서는 목적지의 체중·이동장 규칙과 출처를 확인합니다. 예를 들어 정동진 레일바이크의 ‘6kg 미만’은 6kg 이하로 바꿔 해석하지 않으며, 모르는 종류/조건은 추가 확인으로 남깁니다.

이동이 시작되면 차량 motion을 기준으로 Trip을 관측합니다. 상세 여행 화면과 입력은 잠기며 주행 알림이나 동물의 상태를 추정해 표시하지 않습니다. 앱이 전경에서 유효하게 관측한 펫 동행 시간은 정차 대기를 포함하고, 배경 시간은 더하지 않습니다.

안전하게 정차한 뒤 보호자가 물·산책·물품을 직접 확인하고 쉬었다고 명시할 때 휴식 계획의 다음 간격을 시작합니다. 완료된 드라이브에는 펫 엽서와 한마디를 선택 저장하고 받은 프레임을 적용합니다. 다음 출발에는 자신이 남긴 메모를 확인합니다. 일반 여행 사용자도 기존 동행·기억·무료 시즌을 이용할 수 있습니다. 합성 지역 방문/게임 장면은 별도 여행 체험 앱의 SIMULATED 표시 아래에서 제공합니다.

## 타깃과 발전 방향

주 타깃은 주말 드라이브와 반려동물 동반 나들이를 즐기는 보호자이며, 일반 여행·가족 이동 사용자도 기존 모드를 사용할 수 있습니다. 차량 내 한 화면에서 출발 준비, 정차 시 정보 확인, 여행 기억을 이어주는 이용 맥락을 검증하려 합니다. 동반자의 외형을 키우는 경험에 더해, 보호자별 준비 수첩·휴식 계획·명시 조건 비교라는 실용 기능을 함께 제공하는 것이 카펫의 제안입니다.

반복 이용 구조는 ‘출발 준비 → 이동 관측 → 정차 후 기록 → 펫 엽서/무료 패스 → 다음 출발 메모’입니다. 초기 검증 지표 후보는 등록 후 실제 준비/휴식 세션 사용률, 주간 재사용률, 동반 조건 상세 확인률, 완료 Trip의 엽서 저장률, 기억 재방문률과 무료 패스 참여율입니다. 현재 MAU·Retention·유료 전환·안전/건강 개선의 실측 수치는 없습니다. 사용자 동의와 최소 수집 범위를 먼저 확정하고 사용성 시험으로 가설을 검증할 계획입니다.

확장은 공식 동반 조건 데이터의 지역/종류 확대와 정차 중심 휴식 계획 지원부터 검토합니다. 이후 권리와 운영 조건이 확인되면 지역 관광·반려동물 시설의 정보 연계와 오리지널 테마/꾸미기 패스를 사업 방향으로 검토할 수 있습니다. 현재 체결된 제휴나 결제 매출은 없습니다. 안전 판단과 기본 준비/정보 효용은 캐릭터·보상·결제 여부와 분리합니다.

현재 제공·체험·후속 범위는 [제품 기능](MVP_SCOPE.md), 개발 순서와 확인 조건은 [개발 로드맵](DEVELOPMENT_PHASES.md)을 따른다.
