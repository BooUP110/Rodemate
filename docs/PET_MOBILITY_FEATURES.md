# 반려동물 이동 도우미

2026-11-15 추가. 기존 펫 모드의 기록·패스와 함께 쓰는 **펫 휴식 도우미**와 **동반 조건 검색**이다. 기존 디자인, 차량 Care 판단, 여행·XP·시즌 원장과 차량 제어 경계는 유지한다.

## 펫 휴식 도우미

홈 → 반려동물 동행 → 펫 휴식 도우미에서 시작한다.

1. 보호자가 간격을 선택하거나 15~240분 사이에서 직접 정한다. 자동으로 선택된 기본 간격은 없다. 선택 항목은 의학적으로 적정한 휴식 간격을 뜻하지 않는다.
2. 휴식 계획/확인 기록의 기기 저장에 별도로 명시 동의하고 ‘휴식 동행 시작’을 누르면 앱이 열려 있고 신뢰 가능한 차량 움직임 정보가 있는 구간의 시간을 누적한다. 정차 대기도 포함하는 **동행 타이머**이며 연속 운전·실제 탑승 시간으로 해석하지 않는다. 기존 펫 동의나 간격 선택만으로 세션을 생성하지 않으며 Trip 기록 저장 동의 없이도 독립적으로 사용할 수 있다.
3. 선택한 간격이 되면 정차 화면에서 휴식 계획을 확인한다. 홈의 펫 진입 버튼과 펫 동행 화면에도 확인 안내가 나타난다.
4. ‘함께 쉬기 시작’은 타이머를 멈춘다. 보호자가 확인한 항목을 고르고 ‘휴식 확인하고 다시 시작’을 눌러야 확인 횟수가 증가하고 다음 간격이 시작된다. 정차 자체는 휴식 완료가 아니다.
5. 일시정지·이어가기·종료를 제공한다. ‘휴식 확인 없이 돌아가기’는 확인 횟수와 경과시간을 초기화하지 않는다. 종료하면 이번 타이머/확인 횟수는 제거하고 선택한 간격은 유지한다.

시간은 monotonic clock과 신선한 motion evidence로 계산한다. 전경 상태 상실, 연결/움직임 정보 미확인, 시계 역행, 세션 변경 또는 5초 초과 관측 공백에서 일시정지한다. 차량 상태가 돌아와도 자동으로 재개하지 않는다. 앱 재시작도 저장한 체크포인트에서 일시정지로 복원하며 보호자가 직접 이어간다.

암호화 체크포인트는 최대 15초 간격과 주요 상태 전환/사용자 작업에서 저장한다. 갑작스러운 프로세스 종료로 마지막 체크포인트 이후 최대 약15초의 관측 시간이 누락될 수 있다. 누락 시간이나 백그라운드 시간을 추정해 더하지 않는다. 저장 실패는 오류로 표시하고 민감 화면을 숨긴다.

주행·정책 미확인 때 상세/입력/확인창은 기존 정책으로 잠근다. **이번 구현에는 주행 중 알림, 백그라운드 알람, 음성/TTS, 실내 감지, 반려동물 건강 판단이 없다.** 타이머가 생명·건강 안전 감시를 대신하지 않는다. 실제 휴식 효과나 반려동물의 상태를 판정하지 않고 보호자의 확인만 기록한다.

## 동반 조건 검색

펫 동행 또는 휴식 도우미 → 동반 조건 검색에서 이용한다. 사용자가 TourAPI 인증키 없이 진행하도록 선택한 범위이며, **공식 공개 안내의 사실을 확인해 앱에 담은 오프라인 목록**이다. API 응답·실시간 검색·현재 위치·전국 전체 목록으로 표시하지 않는다.

- 서울4곳, 강릉1곳, 제주3곳을 지역·장소 종류·이름/조건으로 검색한다.
- 등록한 반려동물 종류, 선택적으로 입력한 체중과 이동장 준비 여부를 명시된 조건과 비교한다. 체중·이동장 답변·검색어는 화면 메모리에서만 사용하고 저장하거나 전송하지 않는다.
- ‘일부 조건 일치’, ‘추가 확인 필요’, ‘명시된 조건과 맞지 않음’을 구분한다. 어느 결과도 입장 승인/보장이 아니다. 종류가 언급되지 않은 경우 반려묘/기타를 임의로 허용·금지 처리하지 않는다.
- 체중 **미만**과 **이하**를 혼동하지 않는다. 현재 포함한 수치 제한은 운영사 6kg 미만, 휴애리 7kg 미만이다. 다른 장소의 비어 있는 제한은 무제한이라는 뜻이 아니다.
- 상세에서 주소, 조건, 확인된 항목, 미확인 항목, 이용 구역, 출처 URL, 안내 확인일과 제공되는 원문 갱신일을 보여 준다. 장소 사진·기사 본문·상표 이미지는 복제하지 않았다.
- 확인일로부터 30일을 넘기거나 기기의 날짜가 확인일보다 이전이면 재확인 상태를 표시한다. 날짜와 무관하게 방문 전 현장/운영기관 확인을 안내한다. 실시간 영업·예약·혼잡도·최단 경유지 판단은 제공하지 않는다.

## 저장과 삭제

펫 전용 암호화 파일의 domain schema를2로 확장했다. 기존 schema1을 그대로 읽으며 읽기만으로 파일을 다시 쓰지 않는다. 이후 실제 변경을 저장할 때 기존 프로필·메모·엽서·보상과 함께 schema2로 저장한다. Trip schema/키/저장 경로는 변경하지 않았다.

휴식 세션은 펫 동의에 속하며 특정 Trip에 연결하지 않는다. 일반 모드로 전환하면 진행 중인 준비와 휴식 타이머 종료를 확인한다. 펫 데이터 전체 삭제는 타이머와 선택 간격도 지운다. 원본 Trip 삭제/기록 동의 철회는 기존 연결 엽서·메모에 전파하며, 독립적인 휴식 타이머의 동의를 대신 철회하지 않는다.

새 SDK·dependency·permission·백엔드·외부 전송은 없다. 최신 회귀와 이전 이동 도우미 AVD 관측은 [검증 요약](VALIDATION_SUMMARY.md)에 구분한다. 원시 개발 증거는 로컬 보관소에 보존한다. 실차·전체 접근성·사용자 직접 인수와 배포/정책 승인은 별도다.
