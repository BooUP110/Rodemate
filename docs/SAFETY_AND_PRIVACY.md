# 안전 및 개인정보

이 문서는 현재 구현 정책을 설명한다. **최종 법적 동의 문안이나 Market/DO 승인 문서가 아니며 FINAL_LEGAL_COPY_REQUIRED 상태다.**

## 차량 및 주행 안전

차량 상태 읽기와 차량 제어를 분리한다. 현재 앱은 차량 설정을 변경하지 않는다. 제안에 수락해도 설정 변경 성공을 알리지 않으며 사용자의 수동 조절을 안내한다. ControlGateway는 향후 사용자 승인·권한·Capability·현재 안전 조건·실제 결과 확인을 거쳐야 할 독립 경계다. LLM의 직접 차량 호출 경로는 없다.

Care 안전 등급·우선순위·P1 문구는 동반자·테마·보상·유료 여부와 무관하다. 지역/날씨/정상/위험 등 확인되지 않은 사실을 만들지 않는다. 미지원/미수신/오래된 관측을 정상이나 OFF로 취급하지 않는다.

정차 콘텐츠는 물리적 정차와 플랫폼 UX 허용을 독립 확인한다. unknown/stale/연결 해제/제한이면 기억·회고·시즌·컬렉션·설정 접근을 잠그고 입력·IME·확인창을 제거한다. DO 미선언에 따른 플랫폼 차단을 우회하지 않는다. 현재 분류 후보는 MOBILITY_SERVICES이며 Market/DO 외부 검토가 남아 있다.

## 저장과 동의

| 항목 | 현재 정책 |
|---|---|
| 트립 기록 | 기본 꺼짐. 사용자가 명시적으로 켠 후 앱 로컬 저장 |
| 회고 | 선택 사항. 건너뛰어도 기본 정리 보상은 동일 |
| 별도 기억 | 회고 저장과 구분. 설정 허용과 이야기별 추가 확인 필요 |
| 저장 위치 | 앱 전용 noBackupFilesDir, Production/Demo 경로 분리 |
| 저장 보호 | Android Keystore 관리 AES256-GCM, legacy 데이터 비파괴 migration. 키 누락/인증 실패 시 파일 보존 및 읽기 거부 |
| 명시 온도 선호 | 이 기기에 저장한 USER_INPUT, 자동 학습/운전자 인증 아님. 별도 수정·삭제, encrypted aggregate에 저장 |
| 기억 회상 | 동의한 실제 저장 항목만. 원문은 명시 열기 후 표시, UTC 기간 사실 요약·삭제 즉시 재투영 |
| 외부 전송 | 현재 백엔드·외부 LLM·클라우드 전송 없음 |
| 백업 | allowBackup=false 유지. Android 데이터 이전/추출 규칙은 추가 검토 필요 |

단일/전체 트립 삭제 또는 기록 동의 철회 시 해당 회고·연결된 기억을 제거한다. 이미 획득한 시즌 진행도/보상과 엽서·발견 기록은 원래 Trip 연결을 제거한 뒤 보존하는 현재 정책이다. 모든 데이터가 동시에 완전히 사라진다고 안내하지 않는다. 중복 지급 방지용 가명 키는 익명화 보장을 뜻하지 않는다.

현재 사용자용 시즌 진행 초기화 UI는 없다. 저장 파일은 authenticated encryption으로 보호하지만 서버 원장 검증·전체 유효 파일의 replay 방지·모든 전원 손실 내구성을 보장하지 않는다. 정리 완료 전 회고는 수정할 수 있으며 완료 후에는 읽기 전용이다. 상세 범위는 [저장 보안](PHASE8_6_STORAGE_SECURITY.md)을 따른다.

온도 안내는 정차 중 사용자가 저장한 선호와 실제 센서/front-left 목표 값을 보여주는 수동 안내다. 운전자 존재/신원·자동 공조 조절·안전 경고의 대체 기능이 아니다. Trip 기록 시간과 월간 합계는 연속 운전/실제 휴식/피로 판단이 아니다. 외기는 차량 센서 값이며 날씨·체감온도가 아니다.

## 보상과 Demo

거리·속도·야간 운전·운전 시간·경고·Care 수락에는 XP를 지급하지 않는다. 보상은 안전 기능을 해제하거나 판단을 바꾸지 않는다. Production은 무료 로컬 트랙만 제공하고 구매 기능은 없다.

Demo의 차량/지역/권한/기록/동의 입력은 합성이다. 시나리오 선택이 Demo 기록을 초기화할 수 있으며 실제 사용자 동의·차량 상태·제어 결과의 증거로 사용하지 않는다. 항상 DEMO/SIMULATED를 구분해 설명한다.
