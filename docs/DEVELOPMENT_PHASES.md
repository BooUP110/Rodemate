# 개발 로드맵

현재 기능을 안정적으로 유지하면서 차량 환경의 지원·정책·권리 확인을 마친 영역부터 확장한다. 완료된 구현과 외부 승인·실차 검증은 별개다.

| 단계 | 개발 범위 | 현재 상태 / 다음 확인 조건 |
|---|---|---|
| 1. 기반 | 플랫폼 독립 모델·Adapter·ViewModel/Flow·모의 런타임 | 구현. 실제 관측과 모의 입력의 출처·가용성·신선도를 분리 |
| 2. 차량 맥락 | 실제 Pleos/AAOS 읽기·motion·UX 제한·Trip·결정적 Care | 읽기·Trip/정차 경계 구현. 자동 야간/공조·경고는 신뢰 입력·의미·지원 확인 필요 |
| 3. 기억과 동행 | 오리지널 캐릭터·회고·기억·암호화 저장·무료 시즌 | 로컬 구현. 위치 자동 방문·지역 엽서 발급은 공급자 연결 전 비활성 |
| 4. 여행 표현 | 수채화 홈·지도·엽서·이야기·보상 경험 | UI/로컬 구성 구현, 확장 여행은 모의 체험. 실제 방문/구매/제휴와 구분 |
| 5. 반려동물 | 준비·수첩·펫 엽서·패스·휴식·공식 조건 검색 | 구현. 전경 관측 시간·8곳 오프라인 정보의 범위를 유지 |
| 6. 품질과 배포 | 회귀·서명·문서·설치·접근성 | JVM/빌드·서명 검사. signed APK 별도 설치·새 화면 확대/분할·전체 입력장치 검수 필요 |
| 7. 확장 | 실차·장소/위치·음성·선택형 대화·서비스 운영 | 미구현/미검증. 계정·권한·정책·개인정보·권리·성능을 확인한 뒤 별도 범위 확정 |

차량 제어·LLM·백엔드·결제는 현재 기능으로 표시하지 않는다. 안전 판단·경고 우선순위는 캐릭터·보상·결제와 독립 유지한다. [현재 기능](MVP_SCOPE.md), [검증 현황](VALIDATION_SUMMARY.md), [SDK 경계](SDK_VERIFICATION_MATRIX.md).
