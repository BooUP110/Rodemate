# Production 소스셋

앱 ID는 io.booup.roadmate다. Pleos Vehicle SDK 읽기 및 AAOS motion/UX adapter를 이 소스셋에 격리한다. Demo fallback, host 시나리오 입력, 합성 차량 데이터는 포함하지 않는다.

현재 읽기 범위와 비활성 기능은 [MVP 범위](../../../docs/MVP_SCOPE.md), 안전/정차 제한은 [정책 안내](../../../docs/SAFETY_AND_PRIVACY.md)를 참조한다. DO 선언과 실제 차량 제어는 활성화하지 않았다.
