# 모의 여행 체험 소스셋

앱 ID는 `io.booup.roadmate.demo`이며 DEMO/SIMULATED를 표시한다. 모의 차량 입력·가상 지역·체험 선택 화면은 demoDebug에 있고 실제 차량 연결 앱과 저장 경로를 분리한다. 일반 demoRelease는 비활성이며 별도 내부 preview 구성만 예외다.

모의 데이터는 실제 차량 관측·위치 인증·구매·제어 결과가 아니다. 메뉴는 `더보기 → 여행 체험`이며, [기능 범위](../../../docs/MVP_SCOPE.md)와 [빌드 안내](../../../docs/BUILD_AND_RUN.md)를 따른다.
