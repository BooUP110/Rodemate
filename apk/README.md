# 카펫 Android 앱

[`BooUP_카펫_release.apk`](BooUP_카펫_release.apk)는 실제 Pleos/AAOS 차량 읽기를 사용하는 서명된 release APK다. 앱 ID는 `io.booup.roadmate`, 버전은1.0.0(1)이다.

[설치·빌드](../docs/BUILD_AND_RUN.md) · [현재 SHA256·인증서·검증 범위](../docs/VALIDATION_SUMMARY.md)

기존 개발 APK와 서명이 다르면 사용자 데이터 삭제 없이 별도 AVD에서 확인한다. 키·credential·중간 APK는 이 디렉터리에 넣지 않는다. 공개 트리에는 이 APK 하나만 예외로 포함한다.
